# Hotel Nocturna

Proyecto de clase del módulo **Desarrollo Web en Entorno Servidor (DWES)** de 2.º de Desarrollo de Aplicaciones Web.

Nocturna es la aplicación de gestión de un hotel que estamos construyendo en el aula. Esta carpeta recoge el desarrollo hasta la fecha: el entorno con Docker, la aplicación PHP y la base de datos MySQL.

Hasta ahora el proyecto permite:

- levantar la web y la base de datos con Docker Compose;
- conectar con MySQL mediante PDO, con una única conexión por petición;
- representar una habitación, su precio por noche y su estado (disponible u ocupada);
- recuperar las habitaciones almacenadas y mostrarlas en un panel.

La interfaz del panel usa Twig y una hoja de estilos propia, sobre Bootstrap.

El enunciado del proyecto se añadirá cuando esté cerrado. Mientras tanto, esta carpeta muestra el trabajo realizado en clase.
